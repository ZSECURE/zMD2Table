Email Security Check

Static client-side checker for SPF, DMARC, DKIM selector records, MX, TLS-RPT, and MTA-STS DNS records using DNS-over-HTTPS. No data is sent to your own server.

Browser-only limitation: this checks published DNS and tries to fetch the MTA-STS HTTPS policy. It cannot perform live SMTP STARTTLS or certificate validation against MX hosts because browsers do not provide raw TCP socket access.

Optional backend for real SMTP TLS checks

To add proper TLS checks later, run a small API that connects to each MX on port 25, sends EHLO, checks STARTTLS, upgrades TLS, validates the certificate chain/hostname, and returns the result. A static GitHub Pages site cannot do that by itself.
