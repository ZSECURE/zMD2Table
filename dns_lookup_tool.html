DNS Lookup Formatter

Paste IPs/domains or upload a text file. The tool resolves domains to IPs and reverse-resolves IPs to hostnames, then formats each result like: 8.8.8.8 (dns.google)

One IP/domain per line is best. Commas, spaces, and tabs are also supported.
Browser JavaScript cannot query DNS directly, so this uses public DNS-over-HTTPS APIs.
